documents controlled validation experiments and the reasoning that led to the
frozen pair candidate; it predates the final test result.

The concise joint presentation was the delivered presentation. It remains the
communication reference for the overall project, while the repository
manifest and final-test result files are authoritative for exact submitted
numbers.
