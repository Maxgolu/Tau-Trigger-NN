\label{app:pair_protocol}

\subsection{Constructing the TOB pairs}
For each event, we keep the TOBs with finite measured $\ptTOB$. We sort them by
decreasing $\ptTOB$, using the original TOB index to break exact ties, and form
every unordered pair. An event with $n_e$ retained TOBs therefore produces
$\binom{n_e}{2}$ pairs in a fixed order.

During training, a pair is positive when both TOBs are labelled as tau
candidates and negative when neither is. Pairs with one labelled and one
unlabelled TOB are not used for training. Two positive labels do not prove that
the TOBs match two different generator taus. During validation and testing,
every pair is scored because truth labels are not available to the trigger. No
truth quantity is a network input.

The final test contains $64{,}286$ events, $361{,}685$ finite TOBs and
$866{,}872$ pairs. There are 589 events with fewer than two finite TOBs. These
events remain in the efficiency and fake-rate denominators and cannot pass
through the neural branch.

\subsection{Pair inputs, loss and decision details}
\paragraph{Pair-object models.}
The single-object rule can accept two individually plausible TOBs without
asking whether they form a plausible di-tau candidate. We therefore changed
what the network sees. Within the at-most-six retained TOBs of each event, we
keep those with finite measured $\ptTOB$ and sort them by decreasing $\ptTOB$;
increasing \code{tob\_index} breaks exact ties. Every unordered pair $(i,j)$
with $i<j$ is scored once. We do not add a dummy pair. An event with fewer than
two finite TOBs therefore cannot pass through the neural branch. This keeps the
$\ptTOB$ baseline unchanged: the largest lower $\ptTOB$ among all pairs is the
second-highest finite $\ptTOB$ in the event.

\paragraph{The same encoder is used for both TOBs.}
The final pair model processes both TOBs with the same weights. Each TOB
contributes an unnormalised absolute-scale $12\times12$ EM2 image and a signed
shape channel $E/\max(\sum_{ab}|E_{ab}|,1\,\mathrm{MeV})$, together with the 45
coarse calorimeter cells, measured $\ptTOB$ and $\Frac$. One event-level
second-highest-$\ptTOB$ value is also given to the dense head. A
one-convolution image branch and a 16-unit scalar branch produce a 16-value
representation of each TOB. The two representations and the event value then
enter a $[32,16,1]$ head. The complete model has $4{,}357$ trainable
parameters. Sharing the encoder makes both TOBs follow the same rule, while the
final head can learn whether their calorimeter patterns form a useful pair.

\paragraph{Averaging the loss within each training event.}
The training label is positive when both TOBs are labelled as tau candidates
and negative when neither is. Pairs with one labelled and one unlabelled TOB
are omitted from training; this label does not prove that the two TOBs match
two distinct generator taus. For a positive pair, the $p=-1$ weight
of~\eqref{eq:powerlaw} uses the smaller associated truth momentum; negative
pairs keep unit weight. An event with many TOBs produces many more pairs. If we
simply averaged the loss over pairs, such events would also receive more
weight. We instead average weighted BCE within each eligible training event and
then average those event losses equally. A batch contains all retained pairs from up to 256
shuffled events:
\begin{equation}
  \mathcal{L}_{\mathrm{pair}}
  = \frac{1}{|\mathcal{B}|}
    \sum_{e\in\mathcal{B}}
        \frac{1}{|\mathcal{P}^{\mathrm{train}}_e|}
    \sum_{(i,j)\in\mathcal{P}^{\mathrm{train}}_e}
    w_{e,ij}\,\ell_{\mathrm{BCE}}(s_{e,ij},y_{e,ij}).
  \label{eq:pair_event_loss}
\end{equation}
Here $\mathcal{P}^{\mathrm{train}}_e$ contains the retained same-label
training pairs, and $\mathcal B$ contains only events with at least one such
pair. This removes weighting by pair multiplicity; the signal weights
$w_{e,ij}$ still vary.
Truth information is used only to define training labels and weights. During
validation and testing, the model scores every pair without truth filtering.

\paragraph{From pair scores to one trigger decision.}
Let $\mathcal P_e$ contain all finite unordered pairs at inference.
The neural event score is the maximum pair score,
$s_e=\max_{(i,j)\in\mathcal{P}_e}s_{e,ij}$. The $\ptTOB$ branch uses
$q_e=\max_{(i,j)\in\mathcal{P}_e}\min(\ptTOBof{e,i},\ptTOBof{e,j})$, and the
final event decision is
\begin{equation}
  A_e=\1[s_e\geq t]\vee\1[q_e\geq C].
  \label{eq:pair_decision_details}
\end{equation}
The two branches share one event-level background budget, so an event accepted
by both is counted once. Checkpoints, the neural threshold and the
$\ptTOB$-branch budget are selected on validation independently for seeds 42,
123 and 456.
The three trained models are reported separately and averaged only when the
results are summarised; they are not combined into an ensemble. Exact
construction, training and final-test details appear in
\cref{app:pair_protocol}.

\subsection{How the final model was selected}
The pair study was organised as six questions, with one main change at each
stage:
\begin{enumerate}[label=(\roman*),itemsep=1pt,topsep=2pt]
  \item \textbf{Does the pair pipeline work?} A model using only the two
  measured $\ptTOB$ values checked pair identities, training-only
  normalisation, event reconstruction, threshold calibration and
  reproducibility across three seeds. It did not beat the $\ptTOB$ baseline
  (\path{configs/pair_pt_control/}, \path{results/pt_control/}).
  \item \textbf{Which detector inputs help?} With the model held fixed, we
  compared raw cells, layer summaries and compact shower features. Repeating
  the study across three seeds showed that calorimeter information beyond the
  two measured momenta improved validation efficiency
  (\path{results/representation_study/},
  \path{results/representation_reproduction/}).
  \item \textbf{Does the fine EM2 image help?} We added one shared encoder for
  the two full-granularity EM2 images, followed by the absolute and signed
  two-channel form used by the final model (\path{results/high_resolution/},
  \path{results/high_resolution_two_channel/}).
  \item \textbf{How should the model protect high-energy events?} Controlled
  comparisons motivated the $p=-1$ signal weighting and the direct $\ptTOB$
  branch (\path{results/pair_or/}, \path{results/high_resolution_pt_or/},
  \path{results/pt_factorial/}, \path{results/high_energy_recovery/}).
  \item \textbf{Could a simpler explanation account for the gain?} We tested
  alternative context variables, removed selected inputs, simplified the
  representation and compared shared encoders. Variants that did not improve
  the retained model were not promoted (\path{results/pt_context/},
  \path{results/source_ablation/}, \path{results/clean_representation/},
  \path{results/shared_encoder/}).
  \item \textbf{Which pairs and events should determine the loss?} The final
  validation study replaced the four-leading-TOB limit with all finite pairs
  and averaged loss within each eligible training event before averaging
  across events. This
  fixed the final configuration in
  \path{configs/pair_final_all_finite_equal_event/} before the test in
  \path{results/final_test/}.
\end{enumerate}
All intermediate percentages come from validation. Only
\path{results/final_test/} contains the final test result. The detailed
presentation, \path{presentation/pair_model_research_history.pptx}, preserves
the full experiment sequence and its references.

\subsection{Training and model selection}
The model is trained for 20 epochs with Adam, learning rate $10^{-3}$,
$\beta=(0.9,0.999)$, $\epsilon=10^{-8}$, no weight decay and no AMSGrad. Seeds
42, 123 and 456 use loader seed $424200+\mathrm{seed}$. All three pair models
use the same data split (split seed 42), with training seeds 42, 123 and 456.
Each update contains all retained training pairs from at most 256 shuffled
eligible events and uses the loss in
\eqref{eq:pair_event_loss}. We save one checkpoint per epoch. Validation data
select one epoch and one OR threshold pair for each seed. Normalisation values
inherited from the parent model are checked by hash and are never silently
refitted.

\subsection{Detailed final-test discussion}
\paragraph{Seeing two TOBs together improves the turn-on.}
The selected model scores every pair of finite-$\ptTOB$ TOBs and averages
training losses within eligible events before averaging across events. Unlike the fixed-rate comparisons above,
we did not recalibrate its thresholds on the test set. The checkpoint and both
branch thresholds were selected on validation and then applied unchanged; the
$\ptTOB$ baseline uses
$q_e\geq\SI{19.4}{GeV}$. The final test contains $64{,}286$ events:
$14{,}509$ signal and $49{,}777$ background events. Its $361{,}685$ finite
TOBs form $866{,}872$ unordered pairs; 589 events contain fewer than two finite
TOBs and therefore fail both branches. The selected epochs are 17, 18 and 20
for seeds 42, 123 and 456, respectively.

For this subsection only, signal efficiency is the fraction of signal events
that fire. Elsewhere in the paper it is the fraction of truth-$\tau$ objects
accepted, so the two percentages are not directly comparable. For the
energy-bin results, we choose the first pair in deterministic pair order
among the four highest-$\ptTOB$ TOBs with two positive labels and two finite
truth momenta, and assign the event their lower truth momentum. These
values are therefore also not directly comparable with
\cref{tab:results_main,fig:results_main}.



Across the three models, mean signal efficiency rises from $34.30\%$ to
$46.70\%$, a mean gain of 12.40 percentage points with a standard deviation of
0.32 points across seeds
(\cref{tab:pair_final}). The gain is concentrated in the turn-on energy
ranges: the mean differences are 21.43 points for $10$--$25\GeV$ and
22.19 points for $25$--$60\GeV$, while the already saturated region above
$60\GeV$ gains 0.78 points. This establishes the performance of the selected
pair model; the final test alone does not show which design choice caused the
improvement.

With validation-selected thresholds held fixed, the three pair models exceeded
the $0.5\%$ fake-rate limit ($0.5183$--$0.5223\%$, versus $0.4842\%$ for the
baseline), so the reported gain is not at matched achieved rates.
Exact thresholds, the final success criterion, historical-exposure
qualification and uncertainty procedures appear in \cref{app:pair_protocol}.

\subsection{Final test}
All model and threshold choices were fixed before the final test. The test set
was not used for retraining, checkpoint selection, threshold changes or
recalibration. Signal efficiency uses all $14{,}509$ signal events, including
events without a pair; event fake rate uses all $49{,}777$ background events.

Regional evaluation selects the first eligible pair in deterministic pair
order among the four highest-$\ptTOB$ TOBs, then uses the lower associated
truth momentum. The $10$--$25$, $25$--$60$ and $60\GeV$-and-above regions
contain $1{,}759$, $2{,}811$ and $2{,}612$ signal events, respectively.

The final success criterion requires every seed to satisfy the fake-rate
ceiling, improve the paired point estimate in every region and inclusively,
and pass the Holm-adjusted one-sided high-energy McNemar test at $0.05$.
It is not met; seed 42 also has $p_{\mathrm{adj}}=0.05946$. Any deployment
recalibration requires a separate calibration sample. A repository-local
identity audit found no overlap with the enumerated Phase-5 confirmation
archives; absence of every possible historical or external test exposure
cannot be proven.

Uncertainty is computed from paired event decisions. For each seed, the
conditional two-sided $95\%$ interval, given the observed number of
discordant decisions $b+c$, is obtained from the exact Clopper--Pearson
interval~\cite{clopper1934} for $b/(b+c)$ and transformed to the paired
difference $(b-c)/N$. The one-sided exact McNemar $p$-values for the
high-energy region are Holm-adjusted across the three seeds. We report the
arithmetic mean and sample standard deviation across seeds. Events are not
pooled across seeds, and the three models are not combined into an ensemble.

The public result files intentionally exclude raw detector data, event-level
predictions and trained checkpoints. The submitted verifier checks the public
configuration, implementation and result-file hashes, recomputes the reported
mean and standard deviation, and runs the data-free CPU demo.

\subsection{Lessons from the pair extension}
\paragraph{Let the model see what the decision depends on.}
The trigger asks whether an event contains two useful TOBs, whereas the
original network judged each TOB separately. Scoring TOB pairs gives the model
some event context without requiring a large network over the whole event. The
final test shows that the selected pair model works better, but it does not by
itself show whether the gain came from pairing, the encoder or another design
choice; those questions require matched validation comparisons
(\cref{sec:input_unit,sec:pair_results}).

\paragraph{One event should count once.}
An event with $n$ TOBs produces $n(n-1)/2$ pairs. Averaging BCE over all pairs
would therefore give more weight to events with more TOBs, even though the fake
rate and efficiency count every event once. We first average weighted loss within each eligible training event and then
average those event losses equally. More pairs from one event are not more
independent evidence (\cref{eq:pair_event_loss}).

\paragraph{Keep the final test independent.}
We fixed the thresholds, denominators and success requirements before the
final test, and applied the selected systems unchanged. Future corrections
require a separate calibration sample
(\cref{sec:pair_results,app:pair_protocol}).


The completed pair study motivates extending this direction to a variable-size
event network, averaging training losses within events and using a new
held-out evaluation sample.
